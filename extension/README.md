# WPS 福利自动助手

这是一个作用于 WPS 活动页和 iamtxt 签到页的 Edge/Chromium 扩展。它不读取 Cookie、密码或浏览记录，只在你已经登录的页面里点击页面按钮。

## 它能做什么

- 每天 09:49 自动打开 WPS 任务中心、福利中心与 iamtxt 签到页。
- 任务中心“点击签到”。
- 任务中心签到会同时检查弹窗、短提示和按钮是否变为“已签到”；首次点击未生效时自动重试 3 次。
- iamtxt 顶部“签到”：成功后记录，当天不重复点击；未登录时跳过并提醒。
- 最近记录保留 7 天，显示完整年月日和时分秒。
- 福利中心“打卡免费领会员”。
- 连续打卡满 7 天后，自动领取右侧“集碎片领 1 天超级会员”奖励。
- 会员免费试用中，领取状态为“立刻领取”的 7 天、1 个月、3 个月会员奖励。
- 10:00 先尝试领取 7 天会员卡 1 次，再按原逻辑抢 WPS 大会员和积分。
- 限量爆款处理完后返回 7 天会员卡；遇到“活动太火爆了”或暂无响应会再自动重试 5 次。
- 10:00 前会提前刷新福利页并等待页面完成加载，避免按钮尚未绑定点击事件就开始抢购。
- 会员免费试用中，如有“申请试用”按钮则按页面规则申请。
- 天天抽奖：读取“剩余 N 次”，每次抽完关闭结果弹窗，直到次数用完或触发安全验证。
- 09:59 切换到福利页预热，10:00 刷新后优先领取“WPS 大会员 1 天”。
- 大会员未抢到时自动刷新重试 5 次；仍失败则切换到“WPS 积分 2 分”，再刷新重试 5 次。
- 刷新重试使用扩展状态记录，刷新页面后不会从大会员第一步重新开始。
- 永远不会自动选择第三张“大会员优惠券”，也不会执行任何付费购买。

## 必须知道的两个限制

1. 阿里云滑块验证码不会被绕过。出现验证码时，任务暂停，并发系统通知。你完成滑块后，点扩展里的“立即执行”即可继续。
2. 10:00 的 WPS 大会员只有 120 份，属于先到先得。脚本能在页面已登录且 Edge 保持运行的前提下尽早刷新并点击，但不能保证一定抢到。积分通常更容易成功。

## 安装扩展

1. 在 Edge 地址栏打开 `edge://extensions/`。
2. 打开左侧或页面中的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本文件夹 `WPS福利自动助手`。
5. 在扩展菜单中固定“WPS 福利自动助手”。
6. 打开扩展，点“打开三个页面”，确认 WPS 和 iamtxt 都保持登录状态。
7. 点“立即执行”做一次手动测试。

## 让 Edge 在任务时间前自动启动

仅靠扩展无法在 Edge 完全退出时启动浏览器。若电脑在 09:49 前已开机，可双击或在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\安装定时任务.ps1
```

这会创建一个每天 09:48 以当前 Edge 默认配置打开三个页面的计划任务。它不读取或复制登录数据。

卸载计划任务：

```powershell
powershell -ExecutionPolicy Bypass -File .\卸载定时任务.ps1
```

## 建议设置

- 电脑保持开机，Edge 保持运行，且 Edge 已登录 WPS 和 iamtxt。
- 10:00 前不要关闭自动打开的福利中心标签页。
- 允许扩展发送系统通知，便于验证码出现时及时处理。
- 不要把浏览器设置为退出时清理站点数据，否则 WPS 登录状态会丢失。

## 故障排查

- **到了 10:00 没动作**：查看扩展记录，确认当天是否已经执行过；点“立即执行”可强制重跑。
- **提示安全验证**：切到福利中心，完成滑块，再点“立即执行”。
- **按钮状态是“待开奖”**：表示该轮会员试用已经申请，等待 10:00 开奖，不需要重复点击。
- **提示已抢光**：服务器库存已耗尽，脚本不会再选择第三张优惠券。
- **iamtxt 提示未登录**：在该网站手动登录，然后在扩展中点“立即执行”。
- **扩展未加载**：在 `edge://extensions/` 点该扩展的“重新加载”，再刷新活动页。
